# Essenza Marcenaria

Site institucional responsivo para marcenaria de móveis planejados.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse http://localhost:3000

## Personalização

Edite `app/page.tsx` para trocar:
- nome da empresa
- WhatsApp
- telefone
- cidade
- imagens
- projetos
- depoimentos

O formulário funciona no front-end e exibe confirmação. Para produção, conecte-o a uma API, Resend, Formspree ou backend próprio.

## Deploy

O projeto está preparado para deploy na Vercel.
